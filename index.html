A redesigned Skyward. A home screen with what's happening now, grades with every assignment, your schedule as a timeline, attendance, and the rest of Skyward's menu, all in one app. It reads the Skyward you're already logged in to. Your grades only ever go between your browser and Skyward.

iPhone · iPad · Recommended

Opens by itself after you sign in

A free Safari add-on runs Skyward Glow for you: open Skyward, sign in, and it takes you to your grades in Glow.

  1. Install Userscripts (free) from the App Store, open it once, and tap Set Userscripts Directory → Open.
  2. Open Settings → Apps → Safari → Extensions → Userscripts. Turn it on and set skyward.iscorp.com to Allow.
  3. In Safari, tap Install Skyward Glow. Tap aA (or the puzzle piece) in the address bar → Userscripts → Install.
  4. Tap Open my Skyward and sign in. Glow opens on your grades.
  5. Bookmark that sign-in page (Share → Add to Favorites) so it's one tap from your start page.

Closed Glow? Tap the orange ✦ Glow button at the bottom of any Skyward page to bring it back.

Other way · bookmark

Set up the bookmark (once)

  1. Tap Copy the bookmark code:
  2. Tap the Share button ⬆︎, then Add Bookmark. Name it Skyward Glow and tap Save.
  3. Tap the Bookmarks button 📖, then Edit, and tap Skyward Glow.
  4. Tap the address under the name, delete it all, paste, then tap Done.

Use it

  1. Open Skyward in Safari (the website, not the Skyward app), log in, and go to Gradebook.
  2. Tap the Bookmarks button 📖 and tap Skyward Glow.

If Skyward shows its phone layout instead of the full site, tap aA in the address bar → Request Desktop Website, then open Gradebook again.

Android · Recommended

Opens by itself after you sign in

Chrome on Android can't run add-ons, so this uses Firefox: open Skyward, sign in, and it takes you to your grades in Glow.

  1. Install Firefox from the Play Store and open this page in it.
  2. In Firefox, tap ⋮ → Add-ons → find Tampermonkey → + → Add.
  3. Tap Install Skyward Glow, then Install on the Tampermonkey screen.
  4. Tap Open my Skyward and sign in. Glow opens on your grades.
  5. Bookmark that sign-in page (⋮ → ☆) or add it to your home screen.

Closed Glow? Tap the orange ✦ Glow button at the bottom of any Skyward page to bring it back.

Other way · Chrome bookmark

Set up the bookmark (once)

  1. Tap Copy the bookmark code:
  2. Tap ⋮ (top right), then the ☆ star to bookmark this page.
  3. Tap ⋮ → Bookmarks, then ⋮ next to the new bookmark → Edit.
  4. Change the name to Skyward Glow. Clear the URL, paste, and tap back to save.

Use it

  1. Open Skyward in Chrome (the website, not the Skyward app), log in, and go to Gradebook.
  2. Tap the address bar, type Skyward Glow, and tap the result with the ☆ star. Picking it from the Bookmarks menu won't work; Chrome only runs it from the address bar.

If Skyward shows its phone layout, tap ⋮ → Desktop site, then open Gradebook again.
